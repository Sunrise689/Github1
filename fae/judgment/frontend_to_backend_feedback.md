# 小程序前端 → FAE 后端反馈

本文件是小程序前端向 FAE 后端提交需求和问题的固定入口。后端开始新一轮工作前应先读取本文件；完成项目后，在对应条目下填写“后端处理结果”，不要删除历史记录。

## 2026-08-01 第一次反馈（18:45）

### 优先级：重要

1. 技术图形输出需要提供可直接绘制的结构数据：
   - `geometry.upper_line`
   - `geometry.lower_line`
   - `geometry.neckline`
   - `geometry.pivots`
   - `geometry.breakout_point`
   - `geometry.retest_point`
   - `geometry.target_direction`
2. 上升三角形的下边线必须连接逐步抬高的有效低点；下降三角形的上边线必须连接逐步降低的有效高点。
3. 上升楔形与下降楔形必须同时满足“两条边线方向一致并逐步收敛”，不能仅凭一条倾斜线判断。
4. 旗形需要区分旗杆与平行整理通道；三角旗需要区分旗杆与收敛三角区间。两者不得仅因外观相近而重复输出。
5. 买点或卖点只能在有效突破确认后输出；未突破、假突破或仍处于候选状态时，`trade_point` 必须为 `null`。
6. 杯柄形态使用 `cup_with_handle`：杯口应接近水平，杯底为圆弧，柄部为浅幅回撤；买点只能位于杯口有效突破处。

### 优先级：建议

1. 为小程序提供两种返回模式：
   - `auto`：只返回经过评分、冲突消解和去重后的重要形态、主要技术图形、趋势线、支撑位和阻力位；
   - `detail`：按用户打开的简单形态、组合形态或趋势形态类别返回完整候选。
2. 当同一位置的标签过多时，后端应先进行时间区间合并、互斥消解和重要性排序，不把密集候选全部交给前端绘制。
3. 缺口事件需要区分突破缺口、持续缺口、衰竭缺口和普通噪声；默认视图只返回重要缺口以及已经回补但仍具有结构意义的缺口。

### 当前前端临时处理

- 知识库示意图由前端按标准定义绘制，不代表后端已经检出该形态。
- 买点/卖点仅用于知识库教学示意，真实行情图必须以后端确认字段为准。
- 前端现阶段会对标签数量做显示上限保护，后端仍需要完成根本性的评分、冲突消解与去重。

### 后端处理结果

已处理：后端已接入统一 `pattern_id`/`variant`、Registry 归一、稀疏候选、冲突裁决和结构几何输出。未确认突破时保持 `candidate`，`trade_point` 应由接口层保持 `null`。

岛形底、塔形底新增用户确认的后续确认规则：突破口上方收盘超过 3%，或突破后连续 3 天收盘站稳突破口，满足其一后升级为 `confirmed`。后端信号 metadata 提供 `breakout_level`、`breakout_confirmed`、`breakout_confirmation_mode`、`confirmation_streak_bars` 和 `confirmation_index`。

前端接入细则见：`fae/docs/FAE_前端工程交接说明.md`。

## 2026-08-03 第三次反馈（均线无忧前端入口与接口约定）

### 优先级：重要

1. 首页“均线无忧”入口已从“开发中”切换为可点击入口，前端页面路径为 `/pages/sma/sma`。后端接口接入后，保持该入口和页面结构不变。
2. 请提供统一接口（建议 `POST /api/v1/sma/analyze`），至少接收：
   - `symbol`：市场代码；
   - `lookback_years`：仅允许 `1 / 2 / 3 / 5 / 10`；
   - `method`：`single / cross / triple`；
   - `mode`：`basic / adaptive`；
   - `period`：`daily / weekly / monthly`（可选，默认按接口已有逻辑）。
3. 年限换算由后端按周期和有效交易日计算，不再把 1～1000 作为前端的用户选项；候选均线周期必须受样本长度约束。
4. 单均线规则固定为“收盘价确认站上均线后持有，收盘价确认跌破均线后退出”，不得使用未来数据。双均线、三均线需要返回各周期和交叉确认状态。
5. 返回 `profit_factor`、`trade_count`、`win_rate`、`robustness`、`selected_periods`、`bias_percentile`，并明确 `min_trades` 的实际门槛；交易次数不足的候选不得标为最优。
6. 便宜线、无忧线不是普通短周期均线。候选周期至少满足约 200 个交易日以上，并结合长期回撤恢复、波动率和斜率稳定性判定；若没有满足条件的长期托底线，返回 `trend_broken: true` 和可读说明“长期趋势走坏，不能因为价格低就视为无忧”。

### 当前前端临时处理

- 页面已提供移动平均线、乖离率、盈利因子 PF、最小交易次数的通俗说明。
- 页面当前只保存用户选择并显示“等待计算服务”，没有伪造任何最优周期或价格数值。
- 后端接口上线后，再把真实结果接入结果卡片；需要上传云函数时，请在本文件填写接口版本和部署时间。

### 后端处理结果

已处理。统一 Beta 使用 `GET /api/v1/moving-average`，前端页面路径统一为 `/pages/ma/ma`。接口已返回单均线、双均线、长期安全线、中轴线、乖离率历史分位、盈利因子、胜率和交易次数；未找到满足恢复能力与稳定性要求的长期线时明确返回不可用说明，不强行给出“无忧”结论。

## 2026-08-03 第四次反馈（20:32，统一 Beta 交接）

### 已完成的接口

1. `GET /api/v1/moving-average`
   - 参数：`symbol`、`years`、`min_trades`；
   - 输出：单均线、双均线、长期安全区、中轴线、乖离率分位和图表数据；
   - 约束：回看年限仅允许 1～10 年；长期线从 200 个交易日以上筛选；样本和交易次数不足时不输出伪最优结果。
2. `GET /api/v1/indicators`
   - 参数：`symbol`、`indicator`、`years`；
   - 指标：`macd`、`kdj`、`rsi`、`supertrend`、`id`；
   - `id` 仅描述价格上涨/下跌的集中或分散特征，不生成买卖建议。
3. `GET /api/v1/chan`
   - 参数：`symbol`、`years`；
   - 输出：包含处理后的拐点、笔、中枢与候选信号；
   - 当前为独立 Beta，只将信号标为候选，不宣称完整复现原理论。

### FAE 边界

1. FAE 继续只处理客观形态匹配、确认状态、优先级、冲突消解和去重。
2. 均线参数搜索、技术指标回测和缠论 Beta 是独立分析模块，不写入 FAE 形态先验，不让 FAE 生成趋势预测或操作建议。
3. 图表分析仍先经过现有规则候选与 FAE 裁决；`pattern_core_v7.py` 本轮未修改。
4. 前端真实行情图只绘制后端确认的结构数据；知识库教学图不等同于真实检出结果。

### 后端处理结果

统一 Beta 接口与前端已经接通，真实腾讯行情联调通过。部署后端需使用本轮生成的 CloudBase v4 压缩包；旧的 v3 包不包含本节三个新接口。
