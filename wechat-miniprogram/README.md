# 技术分析大师微信小程序

当前版本包含：

- 月线、周线、日线三周期分析
- 均线无忧：单/双均线、长期安全区、中轴线与乖离率分位
- 指标大师：MACD、KDJ、RSI、SuperTrend 与信息离散度
- 缠中说禅 Beta：拐点、笔、中枢和候选信号
- K线、长期均线、支撑阻力、Zigzag 与趋势线
- K线基础、技术形态与技术图形知识库
- 重要形态（AI识别）筛选与形态分类开关
- 楔形、三角形的支撑阻力线，以及顶底结构的颈线
- 单个识别事件的显示/隐藏
- 客观定义、常见含义、确认条件和规则化结构解读
- Python 分析服务接口；未配置服务地址时原图表分析可使用内置演示数据

“AI识别”指客观形态匹配与冲突筛选，不调用生成式大模型，也不代表价格预测。

## 本地导入

1. 打开微信开发者工具。
2. 导入本目录，即包含 `project.config.json` 的目录。
3. AppID 已写入 `project.config.json`。
4. 直接编译即可查看演示分析。

## 接入分析服务

当前版本默认使用 CloudBase 环境 `cloud1-d5gt0lb2xcd72babe` 的
`technical-analysis-api` 服务。也可以将独立 HTTPS 地址写入
`miniprogram/config.js` 的 `apiBaseUrl`；这种方式需要在微信公众平台配置
`request` 合法域名。
